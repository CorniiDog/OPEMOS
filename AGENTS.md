# Repository agent instructions

`BOUNDARIES.md` is the read-only ownership authority. Do not modify it or its
integrity test during ordinary implementation, cleanup, documentation, release,
or repinning work. A change requires an explicit user request to change project
boundaries. Do not infer that permission from a task that merely touches both
repositories.

Repository summaries may link to the authority but must not contradict it.
Never edit OPEMOS.EXE from this repository's task unless the user separately
and explicitly authorizes that cross-repository mutation.
